# Chat Manager

Простой мессенджер для общения с людьми, где бы они ни находились.

## Веб-версия

Откройте в браузере на компьютере или телефоне:

**https://chat-manager.reifly231.workers.dev**

## Возможности

- Личные чаты и группы
- Отправка фото, видео со звуком и видео «кружочков»
- Ответы на сообщения, реакции, редактирование и удаление
- Поиск людей и сообщений
- Избранное — личное хранилище сообщений и файлов
- Тёмная тема и режим AMOLED для экономии заряда
- Сессии и устройства в профиле
- Восстановление пароля по коду
- Сохранение входа на устройстве

## Приложение для Android

Готовый APK можно скачать в разделе [Releases](https://github.com/MrLyar231/chat-manager/releases).

Установите файл на телефон и пользуйтесь мессенджером как обычным приложением.
