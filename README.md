# Chat Manager — минимальный мессенджер по типу Telegram

Учебный проект: React + Node.js + Socket.io + SQLite + JWT.  
Люди на разных устройствах общаются в реальном времени, сообщения сохраняются в базе.

## Что умеет
- **Как в Telegram:** ответы на сообщения, реакции, редактирование и удаление, отчёты о прочтении (✓✓), поиск по людям и по сообщениям, избранное, редактирование профиля, счётчик непрочитанных
- **Сессии и устройства** как в Telegram: список устройств с IP и временем последней активности, завершение конкретной или всех остальных сессий
- **Восстановление пароля по коду** (код выдаётся при регистрации и показывается в «Профиле»; смена пароля завершает все сессии)
- **Регистрация и вход по @юзернейму и паролю** (PBKDF2 + токены, сессия сохраняется на устройстве)
- **Темы:** светлая, тёмная и AMOLED (чистый `#000` — пиксели выключены, экономит заряд)
- **Иконки:** единый набор встроенных SVG (без внешних библиотек)
- Общий чат для всех + создание личных чатов и групп
- Сообщения в реальном времени (Socket.io)
- История сообщений (SQLite)
- Статус «печатает...» и «в сети»
- Адаптивный интерфейс в стиле Telegram

## Запуск локально

Нужно: **Node.js 18+** и npm (уже установлены на этом компьютере: Node v26.13.1).

### Быстрый запуск (уже готово)
- **`start.bat`** — запуск в один клик: поднимает сервер и открывает готовое приложение на `http://localhost:3000` (клиент уже собран в `client/dist`).
- **`dev.bat`** — запускает два окна: сервер `:3000` и клиент `:5173` с hot-reload для разработки.
- **`remote.bat`** — поднимает сервер + публичный туннель, чтобы общаться с людьми издалека.

### 1. Сервер вручную
```bash
cd server
npm install
npm run dev
```
Запустится на `http://localhost:3000`. База `chat.db` создастся автоматически.

### 2. Клиент (в другом терминале)
```bash
cd client
npm install
npm run dev
```
Откройте `http://localhost:5173`.

### 3. Проверка
1. Нажмите **«Регистрация»**, введите юзернейм (например `alice`) и пароль.
2. Во втором окне (инкогнито) зарегистрируйтесь как `bob`.
3. Оба окажутся в «Общем чате» и увидят сообщения друг друга мгновенно.
4. Кнопка «+ Новый чат» позволяет выбрать людей и создать отдельный диалог/группу.

Правила юзернейма: **5–32 символа**, латиница, цифры и `_`. Пароль — от 6 символов.
Регистрироваться можно и с `@` в начале — он автоматически уберётся.

## Общение между разными устройствами и людьми издалека

Локальный запуск (`localhost`) доступен только с одного компьютера. Чтобы писать
людям, которые находятся далеко, приложение нужно выложить в интернет. В проекте
уже всё готово: сервер отдаёт собранный клиент с **одного порта**, а база хранится
на постоянном диске.

### Удалённая работа прямо сейчас (уже настроено)
Установлен **Cloudflare Tunnel**, сервер и туннель запущены. Публичная ссылка:

```
https://shopper-nails-soonest-trackback.trycloudflare.com
```

Откройте её на телефоне или другом компьютере — всё работает: регистрация,
переписка, сообщения приходят мгновенно. Можно дать ссылку другому человеку,
и он сможет писать и читать из любой точки мира.

**Как поднять заново:** запустите `remote.bat`. Он сам поднимет сервер и туннель
и покажет новую ссылку в окне терминала.

⚠️ Ограничения бесплатного туннеля без аккаунта:
- пока работает только **пока включён этот компьютер** и открыто окно туннеля;
- адрес **меняется при каждом перезапуске** — нужно заново отправлять ссылку;
- это «быстрый туннель» без гарантии аптайма, для серьёзного использования — хостинг ниже.

### Постоянный хостинг: Render (рекомендуется)
1. Залейте папку `chat-manager` на GitHub.
2. https://dashboard.render.com → **New → Blueprint**.
3. Выберите репозиторий — Render прочитает `render.yaml` и создаст сервис.
4. Готово: адрес вида `https://chat-manager-XXXX.onrender.com`.

`render.yaml` уже содержит:
- Docker-сборку (`Dockerfile`): сначала собирает React, потом запускает сервер;
- постоянный диск `/data`, чтобы сообщения не терялись при перезапуске;
- `PORT=10000`, который Render ожидает;
- сгенерированный `JWT_SECRET` — **секрет подписи токенов, его менять нельзя** (иначе все выйдут из аккаунтов).

### Railway
1. https://railway.app → **New Project → Deploy from GitHub repo**.
2. Выберите репозиторий — Railway сам найдёт `Dockerfile`.
3. **Settings → Volumes**: добавьте `/data`.
4. **Variables**: `DB_PATH=/data/chat.db`, `CLIENT_DIST=./public`, `JWT_SECRET=<любая длинная случайная строка>`.
5. **Settings → Networking**: включите публичный домен.

### Важные моменты
- **WebSocket работает** на Render/Railway (в отличие от Vercel serverless).
- **HTTPS** облако даёт автоматически — нужен для сокетов и будущих голосовых чатов.
- Бесплатный план Render засыпает после 15 минут неактивности; первый запрос может занять ~30 сек. Socket.io-client сам переподключится.
- Теперь ссылку можно давать людям: без пароля они не войдут.

## Важно про безопасность
Пароли хешируются через bcrypt, токены — JWT со сроком 30 дней. Это уже намного
лучше учебной версии «вход по имени», но для серьёзного проекта добавьте:
rate-limit, HTTPS (если не облако), смену пароля, подтверждение почты и флаг `httpOnly`
для куки. В облаке HTTPS уже включён автоматически.
